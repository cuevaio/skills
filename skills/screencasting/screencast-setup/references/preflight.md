# Screencast Preflight

Adapt this checklist to the production rather than preserving irrelevant items.

## Content

- [ ] Production brief, bullets, or script is visible off the recorded display
- [ ] Demo starts in the documented state and its reset has been rehearsed
- [ ] Required examples, accounts, files, and local services work
- [ ] Time-sensitive facts and commands were verified

## Room And Presenter

- [ ] Interruptions are controlled and the room is quiet
- [ ] Curtains, rugs, or treatment keep echo acceptable
- [ ] Chair, camera, microphone, and lights match continuity markers
- [ ] Clothing and background match the intended continuity
- [ ] Water is nearby and the presenter has warmed up their voice

## Screen And Privacy

- [ ] Notifications and focus mode are configured
- [ ] Unrelated apps, tabs, desktop icons, toolbars, dock/taskbar, and status items are hidden
- [ ] Password managers, API keys, personal data, customer data, and private bookmarks are absent
- [ ] Wallpaper and physical background are stable and intentional
- [ ] Application zoom, font size, cursor, and display resolution are readable at delivery size

## Capture

- [ ] Correct screen or region is selected
- [ ] Correct microphone is selected and levels do not clip
- [ ] Camera framing, focus, exposure, and white balance are stable when used
- [ ] Required system or application audio is selected
- [ ] Separate source tracks are enabled when available
- [ ] Project canvas, aspect ratio, storage location, and free disk space are confirmed
- [ ] Record and stop controls are known
- [ ] Sync mark is planned when sources start separately

## Proof

- [ ] A fresh test was recorded
- [ ] The test was played back with headphones
- [ ] Every source is present, synchronized, readable, and free of private material
