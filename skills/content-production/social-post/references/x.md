# X Adapter

## Shape

Write for fast scanning and public conversation:

- lead with the useful observation, tension, result, or point of view
- keep a single post when the idea fits without compression damage
- use a thread only when each post advances a necessary step
- make the first post useful even if the reader never opens the thread
- use line breaks to clarify thought, not to manufacture drama

Prefer concrete nouns and verbs. Keep hashtags rare and functional. Use emoji only when supported by the creator's style profile.

## Links And Media

State the useful idea before asking for a click. When media contains the proof, reference what to notice rather than repeating every visible detail. Supply alt text for meaningful images.

Do not claim reach penalties or algorithm effects without current first-party evidence. Choose link placement based on the post's communication job and current preview behavior.

## Threads

Every entry should have one function: setup, evidence, step, objection, example, implication, or action. Remove entries that only tease the next one. End when the argument lands.

## Package Checks

- meaning survives truncation and reposting
- mentions and links point to the intended accounts/pages
- media order is correct
- alt text describes meaning, not decoration
- personal claims are confirmed
