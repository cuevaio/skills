# Instagram Adapter

## Package Types

Identify the actual unit:

- Reel
- carousel
- image post
- Story sequence

The caption complements the media; it does not need to repeat the full script or every carousel slide.

## Caption Shape

- use the first visible line for context, tension, or the useful promise
- add only the context the media cannot carry
- preserve the creator's natural tone and line rhythm
- make the CTA specific and proportionate
- use relevant hashtags only when they help categorization or discovery

Avoid generic “save this” instructions unless saving genuinely helps, hashtag blocks detached from the topic, and captions that describe visuals without adding meaning.

## Reels

Package:

- cover title readable in the profile grid crop
- burned-in captions and corrected platform captions when available
- caption copy
- alt text or accessible description where supported
- optional pinned comment that adds a source, clarification, or useful next step

Keep critical text inside current safe zones. Preview the Reel with live interface controls before publication.

## Carousels

Each slide advances one step. Slide one makes a specific promise; the final slide lands the idea before the CTA. Caption copy should add context, sources, or personal perspective rather than transcribing the deck.

## Package Checks

- profile-grid and feed crops preserve the cover
- first line and media communicate the same promise
- caption, tags, collaborators, location, and links are intentional
- alt text communicates the meaningful visual content
- claims and personal experience are confirmed
